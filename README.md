## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Dread Admiral**. This trainer provides optional quality-of-life advantages for Dread Admiral's campaign and tactical naval battles. It supports resource management, fleet preservation, Flagship survivability, and campaign time pressure while leaving the game's turn-based command structure intact.

**Target Audience:** Players who want to experiment with fleet compositions, explore campaign routes, reduce roguelite frustration, test tactical strategies, or replay missions without permanent ship losses.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Resources** — Prevents campaign resources from decreasing when building ships, managing the fleet, or preparing for missions.
- **Unlimited War Chest** — Keeps persistent campaign funds available for purchases and strategic decisions between missions.
- **No Ship Losses** — Protects ships from permanent loss when they are destroyed during the campaign.
- **Unlimited Mission Turns** — Stops the campaign timer from advancing, delaying the Black Fleet's pressure and allowing more time to complete objectives.
- **Instant Technology Unlocks** — Makes available technology and Flagship upgrade progression easier to access where supported by the current campaign.

### ⚔️ Combat

- **Maximum Flagship Health** — Restores or maintains the Flagship's health during naval engagements.
- **Unlimited Repairs** — Allows damaged vessels to be repaired without consuming normal repair resources.
- **Unlimited Movement** — Removes movement restrictions during tactical turns so ships can reposition freely.
- **Unlimited Actions** — Allows the selected ship to continue performing available actions during alternating-activation battles.

## 📖 Detailed Feature Guide

### Movement & Exploration

Dread Admiral uses turn-based fleet movement across an archipelago and tactical positioning during naval engagements. Select the movement-related option before issuing orders, then disable it when normal movement limits are preferred.

### Tools & Inventory

The game does not use a conventional character inventory. Its equivalent systems are campaign resources, the persistent war chest, fleet composition, technology, Perks, and Flagship upgrades. Resource options should be activated before purchasing ships or upgrades.

### World & Environment

Campaign missions offer different objectives, rewards, and modifiers, while the Black Fleet advances as turns pass. The unlimited-turn option is intended for exploring maps, gathering resources, and testing mission modifiers without the normal time pressure.

### Combat & Weapons

Combat uses alternating activations in turn-based naval battles. Select a ship before enabling movement, action, health, or repair options. Protecting the Flagship is especially useful because its destruction can end a campaign, while preventing ship losses removes the game's permanent-loss consequence.
